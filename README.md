# Day 1 – Brand Name Generator 🧠

This is my first project from the **100 Days of Python** challenge.  
It’s a simple program that helps you create a catchy brand name by combining the name of your city and your pet’s name.

## 🧩 How It Works
1. The program asks for the name of the city you grew up in.  
2. Then it asks for your pet’s name.  
3. It combines both to generate a fun brand name suggestion.

Example:
City: Paris
Pet: Coco
Your brand name could be: Paris Coco
